# Wave 4 plan (design, branding, accessibility)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:**
- ShopLi gets a consistent visual identity based on the logo: colors, the logo on the login screen, vector icons instead of emoji, and a uniform header.
- Every interactive element gets Hebrew screen-reader labels, roles and states.

**Architecture:**
- All colors come from `src/theme/colors.js`, and only that file changes the palette.
- Icons come from `react-native-vector-icons/MaterialCommunityIcons`. It is already installed and the fonts gradle line is already applied.
- Accessibility is done with props only. `testID`s stay unchanged, so Jest keeps working.

**Tech Stack:** React Native 0.86, Jest and react-test-renderer.

**Spec:** `docs/superpowers/specs/2026-11-23-improvements-round-2-design.md`, the section "גל 4".

## Review Focus
1. A missing icon glyph name renders as "?". Every icon name used must exist in MaterialCommunityIcons. Add a test that checks each name against the glyph map.
2. Contrast: white text on `primaryLight` (the active chips) is too weak. Active chips use `primary` background with white text.
3. Disabled and offline controls (wave 3) must expose `accessibilityState={{ disabled: true }}`.
4. An item row exposes its purchased state as a checkbox: `accessibilityRole="checkbox"` with `accessibilityState={{ checked }}` on the toggle.
5. Dynamic labels (list names, member names, suggestion chips) are full Hebrew phrases. Examples: `פעולות לרשימה ${name}`, `הסר את ${name}`, `הוסף ${chip}`.
